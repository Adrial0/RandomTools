# Character portraits

Put your images in this folder. Name each file after the card ID: `robot.png`, `space-monk.png`, `ai-girlfriend.png`, etc. `image-filenames.json` lists every card and summon filename.

PNG, WebP, JPG, and JPEG work automatically, searched in that order. Use lowercase filenames and extensions. Reload the game after adding images; no build is needed. Upgraded Blobs use `blob.png`.

Square portraits work best for the battlefield. Images fill their area and crop from the center. The detail window also reserves a portrait area. Missing images use a silhouette, so no images are required to play.
